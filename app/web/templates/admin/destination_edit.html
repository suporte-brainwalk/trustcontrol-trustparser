Pacote para o Wazuh

O Wazuh precisa do decoder do Trust Parser para ler o JSON depois do cabeçalho syslog. Confirme a versão do manager: 4.x usa XML; 5.x mudou o motor (YAML) e não recebe syslog direto.

  • trustparser_decoders.xml (4.x · /var/ossec/etc/decoders/)
  • trustparser_rules.xml (4.x · /var/ossec/etc/rules/)
  • trustparser-wazuh5-integration.yml (5.x · rascunho)
  • LEIA-ME.md (passo a passo)
