Chaves para sistemas da Trust Control usarem o Trust Parser pela API em {{ api_base }} (acessível só do Brasil). Cada chave tem escopo (global ou um tenant), permissões por tipo de dado, validade e IPs permitidos. Chaves de leitura consultam os dados; chaves de escrita fazem pela API o que o admin faz na tela (tenants, fontes, IPs do firewall, destinos, parsers, uploads, Estúdio IA, pessoas e EVA), com as mesmas regras — exigem IPs de origem, o seu código MFA e fazem no máximo 10 alterações por minuto. Toda criação, revogação, rotação e alteração feita pela API fica na auditoria.
